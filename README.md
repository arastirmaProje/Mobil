Personelim 📱

Personelim is a personnel management application developed collaboratively as a Software Engineering graduation project at Doğuş University.

The application aims to simplify business and personnel management by bringing together tools for managing employees, tasks, attendance, and leave requests in a centralized platform.

This repository contains the iOS mobile application, built with Swift and SwiftUI.

✨ Features

* Personnel Management: View and manage personnel information.
* Task Management: Track assigned tasks and their statuses.
* Attendance Tracking: Support location-based attendance and shift operations.
* Leave Management: Manage employee leave requests.
* Performance Reports: Access personnel performance information.
* AI Assistant: Interact with an AI-powered chat interface.
* Role-Based Access: Provide functionality based on user roles and permissions.

🛠️ Technologies

* Swift
* SwiftUI
* MVVM Architecture
* REST API Integration
* Figma — UI/UX design and prototyping
